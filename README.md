# KVVI Minimal Markdown Viewer

**可微MD极简阅读器**是一款只读、离线、极简的 macOS Markdown（`.md`）预览器。它面向只想舒服阅读 Markdown、又不需要代码编辑功能的用户。

## 系统要求

- Apple 芯片 Mac（M1、M2、M3、M4 或后续型号）
- macOS 13 Ventura 或更高版本
- 不需要联网，不需要账户

## 安装

1. 下载并解压 `可微MD极简阅读器.zip`。
2. 将 `可微MD极简阅读器.app` 拖入“应用程序”文件夹。
3. 第一次打开时，在 Finder 中右键应用，选择“打开”，再在系统提示中确认“打开”。

这是本地临时签名版本，没有提交 Apple 公证。首次打开时使用“右键 → 打开”是正常现象。

## 使用方法

- 点击应用中的“打开文件”，选择 `.md` 或 `.markdown` 文件。
- 将 Markdown 文件直接拖入窗口。
- 在 Finder 中选中 `.md` 文件，右键选择“打开方式 → 可微MD极简阅读器”。
- 工具栏的缩小、放大按钮可在 14–28 号之间调整正文字号。
- 点击打印按钮可打开 macOS 系统打印面板，也可在打印面板中“存储为 PDF”。

### 设为 `.md` 默认程序

1. 在 Finder 中选中任意 `.md` 文件并按 `Command + I`。
2. 展开“打开方式”，选择“可微MD极简阅读器”。
3. 点击“全部更改”。

之后双击 `.md` 文件即可用本应用打开。

## 隐私与安全

- 完全离线：Markdown 渲染库随应用提供，阅读时不从网络下载代码或字体。
- 严格只读：应用不会保存、覆盖或修改原始 Markdown 文件。
- 远程图片不会加载，只显示占位文字。
- 本地图片只能从当前 Markdown 文件所在目录及其子目录读取；越界路径和符号链接会被阻止。
- 原始 HTML 不会执行，外部链接只有在用户点击后才交给系统浏览器。
- 无账户、无同步、无遥测、无插件。

## 第一版限制

- 仅支持 macOS 和 Apple 芯片。
- 不提供 Markdown 编辑、目录侧栏、全文搜索、导出管理或多标签页。
- 单个 Markdown 文件最大 20 MB；本地图片单个最大 20 MB。
- 远程图片不会显示。

## 卸载

退出应用后，将“应用程序”文件夹中的 `可微MD极简阅读器.app` 移到废纸篓即可。本应用不会创建账户或云端数据。
