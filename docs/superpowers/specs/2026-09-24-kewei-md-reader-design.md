# 可微MD极简阅读器设计文档

## 1. 产品目标

“可微MD极简阅读器”是一款面向不熟悉代码的 macOS 用户的本地 Markdown 只读工具。用户安装应用并将其设为 `.md` 文件的默认打开程序后，可以直接双击 Markdown 文件，以排版后的阅读视图查看内容。

第一版只解决“轻松阅读 Markdown”这一件事。应用不提供编辑、保存、账号、同步、插件、主题市场或云端服务，避免复杂界面和误改原文件。

## 2. 成功标准

- 用户能够通过双击、文件选择器或拖放打开 `.md` 文件。
- Markdown 以清晰的排版视图呈现，而不是显示源代码符号。
- 应用不能修改或删除原文件。
- 阅读功能完全离线可用，文件内容不会上传网络。
- 非技术用户无需理解 Markdown 或编程概念即可使用。
- 常见异常以简明中文提示，不显示技术堆栈，也不导致应用崩溃。

## 3. 平台与交付范围

- 目标平台：macOS。
- 首要运行环境：Apple 芯片 Mac。
- 兼容目标：在工具链允许的情况下兼容较新的 Intel Mac。
- 交付形式：`可微MD极简阅读器.app`、ZIP 压缩包、完整源代码、中文使用说明和示例 Markdown 文件。
- 分发范围：第一版供用户自己的 Mac 使用，不发布 App Store，也不依赖付费开发者账号。
- 首次启动：未进行 Apple 公证时，用户可能需要右键应用并选择“打开”。

## 4. 技术方案

采用原生 macOS 架构：

- SwiftUI：窗口、工具栏、空状态、文件选择和错误提示。
- WKWebView：承载排版后的 Markdown 阅读页面。
- 随应用打包的 Markdown 渲染资源：在本机将 Markdown 转换为 HTML，不从网络加载运行时代码。
- 应用文档类型注册：声明支持 `.md` 和 `.markdown` 文件，使应用可被设为默认打开程序。

不选择 Electron，原因是安装包和运行资源相对于单一只读功能过重；不选择纯网页，原因是无法自然支持 Finder 双击打开本地文件。

## 5. 组件边界

### 5.1 AppShell

负责应用生命周期、窗口和 macOS 打开文档事件。它只协调其他组件，不解析 Markdown。

### 5.2 DocumentLoader

负责接收文件 URL、校验扩展名和读取 UTF-8 文本。读取失败时返回面向用户的错误类别，不修改文件。

### 5.3 MarkdownRenderer

负责把 Markdown 文本转换成经过安全处理的 HTML。渲染器禁用或清理可执行脚本和危险 HTML，只输出阅读所需的结构。

### 5.4 ReadingView

负责在 WKWebView 中加载 HTML、应用排版样式、跟随浅色或深色模式，并处理字号缩放。

### 5.5 ResourceResolver

负责解析 Markdown 文件旁的相对路径图片。资源访问限制在当前 Markdown 文件所在目录及系统明确授权的文件范围内。

### 5.6 LinkHandler

拦截网页链接，交给 macOS 默认浏览器打开。应用本身不作为网页浏览器使用。

### 5.7 PrintCoordinator

调用系统打印面板。用户可通过 macOS 打印面板选择打印机或“存储为 PDF”，应用不单独实现导出系统。

## 6. 数据流程

1. 用户双击、选择或拖入 Markdown 文件。
2. AppShell 将文件 URL 交给 DocumentLoader。
3. DocumentLoader 校验并读取文本，同时保留文件所在目录用于解析本地图片。
4. MarkdownRenderer 将文本转为安全 HTML，并套用内置阅读样式。
5. ReadingView 显示结果。
6. 用户调整字号时只改变阅读样式，不重新写入文件。
7. 用户点击网页链接时由 LinkHandler 调用默认浏览器。
8. 用户点击打印时由 PrintCoordinator 打开系统打印面板。

## 7. 界面设计

### 7.1 空状态

应用首次启动且没有打开文件时，窗口中央显示：

> 打开或拖入一个 Markdown 文件

同时提供一个“打开文件”按钮。

### 7.2 阅读状态

窗口顶部只有一行工具栏：

`打开文件`　`文件名`　　　　　　　　　`缩小`　`放大`　`打印`

正文采用居中的白色或深色阅读页面，设置适合中英文阅读的最大行宽和留白，不让文字铺满宽屏。

### 7.3 支持的 Markdown 内容

- 标题和段落
- 粗体、斜体和删除线
- 有序列表和无序列表
- 引用
- 表格
- 行内代码和代码块
- 链接
- 任务列表和勾选框的只读显示
- Emoji 和中英文混排
- 相对路径本地图片

第一版不承诺公式、Mermaid 图表、远程图片下载或 Markdown 扩展插件。

## 8. 只读与安全要求

- 应用不提供编辑控件、保存命令或文件写入路径。
- Markdown 内容全程在本机处理，不上传、不统计、不遥测。
- 禁止 Markdown 中的脚本执行。
- 对原始 HTML 采用禁用或严格清理策略。
- 不允许 Markdown 自动发起网络请求；网页链接必须由用户点击后才交给默认浏览器。
- 本地资源访问遵循 macOS 文件权限和沙盒授权范围。

## 9. 异常处理

- 非 Markdown 文件：提示“请选择 Markdown 文件”。
- 文件不存在、无权限或读取失败：提示“无法读取该文件”。
- 文本编码无法识别：提示“暂时无法识别该文件的文字编码”。
- 图片不存在：正文继续显示，并在对应位置显示图片缺失占位。
- Markdown 不规范：尽可能显示可识别内容，不中断整个页面。
- 大文件：显示加载状态；超过预设安全上限时提示文件过大，不无休止占用内存。
- 渲染失败：显示“无法显示该文件”，同时允许用户重新选择文件。

## 10. 测试与验收

### 10.1 自动化测试

- DocumentLoader：合法扩展名、错误扩展名、无权限、空文件、UTF-8 中文和大文件边界。
- MarkdownRenderer：常见 Markdown 语法、危险脚本清理、异常输入和相对图片路径。
- LinkHandler：外部网页链接被拦截并交给系统，不在 WebView 内导航。
- 只读约束：核心模块没有写入源文件的代码路径。

### 10.2 应用级验证

- 从 Finder 双击 `.md` 能启动应用并显示文件。
- 从“打开文件”和拖放两种入口均可阅读。
- 中文、英文、Emoji 和常用 Markdown 元素显示正常。
- 相对路径本地图片显示正常；缺失图片不会导致崩溃。
- 浅色和深色模式显示正常。
- 缩小、放大和打印可用。
- 断网情况下全部阅读功能正常。
- 打开异常文件时不闪退，并显示简明中文提示。
- 阅读前后原始 `.md` 文件内容和校验值保持不变。

## 11. 明确不做的功能

第一版不包括：

- Markdown 编辑和保存
- 文件夹侧边栏或知识库管理
- 多标签页
- 账号、同步或云存储
- 插件系统和主题市场
- App Store 发布、开发者签名和 Apple 公证
- 公式、Mermaid、远程图片下载
- 自动更新和使用数据收集

这些功能只有在第一版只读体验稳定、且用户提出明确需求后才重新评估。

## 12. 完成定义

以下条件全部满足才视为第一版完成：

1. 自动化测试通过。
2. 在目标 Apple 芯片 Mac 上完成 Finder 双击、拖放、文件选择、字号和打印验证。
3. 使用覆盖常见语法的示例文件完成浅色和深色模式人工检查。
4. 验证恶意脚本不会执行，阅读过程不会修改源文件。
5. 生成可运行的 `.app` 和 ZIP 包，并附中文使用说明及源代码。
